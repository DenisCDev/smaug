## Stack rules

- A stack rule arrives once, as a denial on the first edit of a file it governs: keep applying it.

## Antigravity adaptations

- `smugan` denials stop a write before it lands: fix the named violation and retry.
- Post-write eslint failures return as a "deferred" denial at the next write or turn end: fix them.
- `smugan stop:` holds a red Definition of Done open: fix the failures; past the attempt cap, report what's left. Release isn't approval.

## Answers

- Lead with the answer: no preamble, closing summary or process narration.
- Short prose; headings, tables and bullets only for real lists or comparisons.
- One recommendation, not a menu; the user's decision gets one question.
- Omit the user's own setup unless it changes what they must do; no unrequested notices.
- Plain words.
- Say what a thing does before naming it; consequence before mechanism.
- Brevity never cuts evidence: the command, its result and the `file:line` stay.
